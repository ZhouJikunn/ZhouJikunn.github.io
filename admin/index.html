CONTENT MAINTENANCE

网站维护中心

内容存放在 GitHub 仓库的一个数据文件中。点击下方入口，登录 GitHub 后即可在线编辑；保存提交后，主页通常会在几分钟内自动更新。

说明：GitHub Pages 没有传统数据库后台。这里使用 GitHub 的权限与版本记录作为安全后台，只有拥有仓库写入权限的人可以发布更改。
01 · PROFILE

编辑全部主页内容 ↗

修改姓名、单位、简介、研究方向、经历、论文、动态和社交链接。

02 · FILES

上传简历或附件 ↗

上传 CV、论文附件或其他公开文件；CV 建议命名为 cv.pdf。

03 · HISTORY

查看更新历史 ↗

每次修改都有记录，可以查看差异或恢复到先前版本。

04 · ARCHIVE

旧课程主页 ↗

访问迁移前的“计算物理 B”课程内容与资料链接。

更新步骤
  1. 点击“编辑全部主页内容”，登录 GitHub。
  2. 只修改引号内的文字；新增经历、论文或动态时复制一个完整的对象。
  3. 点击页面底部的 Commit changes，主页会自动重新发布。
